# Auto Service

## Getting Started

Requirements:

- Node.js 24
- Yarn

### Quick Start

```sh
yarn install

yarn dev

yarn build
```

##  Structure

```sh
├── public/
│   └── assets/              # Static assets
├── src/
│   ├── components/          # Reusable UI components
│   ├── content/
│   ├── layouts/
│   ├── pages/
│   └── styles/              # SCSS styles
├── package.json             # Dependencies and scripts
├── pagescms.json            # Pages CMS configuration
└── README.md                # Project documentation
```
