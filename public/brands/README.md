# Brand logo sources

The automotive brand marks in this directory are bundled locally so the site does not depend on a runtime CDN.

- Most SVGs come from `vehiclespecs/brand-logos` at commit `3f0929e70e0a9a2a502063edc4b3e5c0146cba74`.
- `ford.svg` and `honda.svg` come from `simple-icons/simple-icons` at commit `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`.
- The Simple Icons source project is CC0-1.0. Its license applies to the icon artwork, not to the represented trademarks.
- Vehicle brand names and marks remain the property of their respective owners. The source repository explicitly notes that its collection license does not relicense those marks.
